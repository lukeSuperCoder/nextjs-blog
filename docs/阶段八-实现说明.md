# 阶段八（搜索、主题切换、SEO）实现说明

## 8.1 主题切换

- 依赖：`next-themes`（已安装）
- Provider：`src/components/theme-provider.tsx:1`
- Toggle：`src/components/theme-toggle.tsx:1`
- 接入：`src/app/layout.tsx:1`（`ThemeProvider` 包裹 `Providers`）
- 导航栏入口：`src/components/navbar.tsx:1`

## 8.2 搜索

- 搜索页：`src/app/(frontend)/search/page.tsx:1`（CSR + 500ms 防抖）
- API：`src/app/api/search/route.ts:1`（Prisma `contains` 模糊匹配，限制 `take: 20`）
- 结果展示：复用 `PostCard`，并兼容 API 序列化日期：`src/components/post-card.tsx:1`

## 8.3 SEO

- `sitemap.xml`：`src/app/sitemap.ts:1`（包含首页、文章列表、文章详情；数据库不可用时回退为静态页面）
- `robots.txt`：`src/app/robots.ts:1`（屏蔽 `/dashboard/`、`/api/`、`/login`、`/register`）
- 站点配置：`src/config/site.ts:1`
  - 生产环境建议设置：`NEXT_PUBLIC_SITE_URL`
- 结构化数据（JSON-LD）：`src/app/(frontend)/posts/[slug]/page.tsx:1`
