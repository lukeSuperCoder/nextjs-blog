# 个人博客/知识管理系统 - 项目需求概述

## 一、项目背景与目标

### 1.1 项目定位
一个现代化的个人博客和知识管理系统,用于学习和掌握 React 18+ 和 Next.js 14+ 的核心特性和最佳实践。

### 1.2 学习目标
- 掌握 Next.js App Router 的使用
- 理解 SSR、SSG、ISR 等渲染策略的应用场景
- 学习 Server Components 和 Client Components 的区别与使用
- 实践 React 18+ 的新特性 (Suspense、Streaming、Server Actions 等)
- 掌握全栈开发流程 (前端 + 后端 API + 数据库)
- 学习现代化的状态管理和表单处理方案
- 实践 SEO 优化和性能优化技巧

### 1.3 项目特点
- 功能完整但不过度复杂
- 注重代码质量和最佳实践
- 突出 Next.js 技术栈优势
- 具有实际使用价值

## 二、功能模块设计

### 2.1 前台展示模块 (面向访客)

#### 2.1.1 首页
- **布局**: 响应式布局,支持移动端和桌面端
- **内容**:
  - Hero 区域: 个人简介、头像、社交链接
  - 最新文章列表 (5-10篇)
  - 热门文章推荐
  - 标签云
- **技术要点**: SSG (Static Site Generation) 生成静态页面

#### 2.1.2 文章列表页
- **功能**:
  - 文章卡片展示 (标题、摘要、封面图、发布时间、标签)
  - 分页或无限滚动加载
  - 按分类筛选
  - 按标签筛选
  - 搜索功能
- **技术要点**: ISR (Incremental Static Regeneration) 定时重新生成

#### 2.1.3 文章详情页
- **功能**:
  - Markdown/MDX 内容渲染
  - 代码高亮显示
  - 目录导航 (TOC)
  - 阅读进度条
  - 上一篇/下一篇导航
  - 评论区 (可选)
  - 点赞功能
  - 分享按钮
- **技术要点**: SSR 或 SSG,支持动态路由

#### 2.1.4 分类/标签页
- **功能**:
  - 展示所有分类/标签
  - 点击进入对应的文章列表
  - 显示文章数量
- **技术要点**: SSG

#### 2.1.5 关于我页面
- **功能**:
  - 个人介绍
  - 技能栈展示
  - 项目经历
  - 联系方式
- **技术要点**: SSG

#### 2.1.6 搜索页面
- **功能**:
  - 全文搜索
  - 搜索建议/自动补全
  - 搜索结果高亮
- **技术要点**: Client-side rendering + API

### 2.2 后台管理模块 (面向博主)

#### 2.2.1 仪表盘 (Dashboard)
- **功能**:
  - 文章统计 (总数、已发布、草稿)
  - 访问统计 (PV、UV) - 可选
  - 最近文章列表
  - 快捷操作入口
- **技术要点**: SSR + API Routes

#### 2.2.2 文章管理
- **文章列表**:
  - 表格形式展示所有文章
  - 筛选 (状态: 已发布/草稿/已删除)
  - 排序 (按时间、按标题)
  - 批量操作 (删除、修改状态)
  - 搜索功能

- **创建/编辑文章**:
  - Markdown 编辑器 (支持实时预览)
  - 标题、摘要、封面图
  - 分类、标签选择 (支持多选和新建)
  - 发布状态 (草稿/发布)
  - SEO 设置 (自定义 slug、描述、关键词)
  - 保存草稿
  - 定时发布 (可选)

- **技术要点**:
  - React Hook Form 处理表单
  - Server Actions 提交数据
  - Optimistic UI 更新

#### 2.2.3 分类管理
- **功能**:
  - 添加/编辑/删除分类
  - 分类描述
  - 显示每个分类的文章数量
- **技术要点**: CRUD 操作

#### 2.2.4 标签管理
- **功能**:
  - 添加/编辑/删除标签
  - 标签颜色自定义
  - 显示每个标签的文章数量
  - 标签合并功能
- **技术要点**: CRUD 操作

#### 2.2.5 媒体库
- **功能**:
  - 图片上传 (拖拽上传)
  - 图片预览
  - 图片管理 (重命名、删除)
  - 图片裁剪和压缩
- **技术要点**: File Upload + Image Optimization

#### 2.2.6 系统设置
- **功能**:
  - 网站基本信息 (标题、描述、Logo)
  - 个人信息设置
  - 社交媒体链接
  - SEO 设置
  - 外观设置 (主题色等)
- **技术要点**: 配置管理

### 2.3 用户认证模块

#### 2.3.1 登录/注册
- **功能**:
  - 邮箱密码登录
  - GitHub OAuth 登录 (可选)
  - 记住登录状态
  - 密码重置 (可选)

## 三、数据库设计

### 3.1 数据表结构

#### 3.1.1 用户表 (users)
```prisma
model User {
  id            String    @id @default(cuid())
  name          String?
  email         String    @unique
  emailVerified DateTime?
  image         String?
  password      String?   // hash
  role          String    @default("visitor") // admin, visitor
  createdAt     DateTime  @default(now())
  updatedAt     DateTime  @updatedAt

  posts         Post[]
  accounts      Account[]
  sessions      Session[]
}
```

#### 3.1.2 文章表 (posts)
```prisma
model Post {
  id          String    @id @default(cuid())
  title       String
  slug        String    @unique
  content     String    @db.Text
  excerpt     String?   // 摘要
  coverImage  String?
  status      String    @default("draft") // draft, published
  views       Int       @default(0)
  likes       Int       @default(0)

  // SEO
  metaTitle       String?
  metaDescription String?
  metaKeywords    String?

  publishedAt DateTime?
  createdAt   DateTime  @default(now())
  updatedAt   DateTime  @updatedAt

  authorId    String
  author      User      @relation(fields: [authorId], references: [id])

  categoryId  String?
  category    Category? @relation(fields: [categoryId], references: [id])

  tags        Tag[]
}
```

#### 3.1.3 分类表 (categories)
```prisma
model Category {
  id          String   @id @default(cuid())
  name        String   @unique
  slug        String   @unique
  description String?
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt

  posts       Post[]
}
```

#### 3.1.4 标签表 (tags)
```prisma
model Tag {
  id        String   @id @default(cuid())
  name      String   @unique
  slug      String   @unique
  color     String?  // hex color
  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt

  posts     Post[]
}
```

#### 3.1.5 评论表 (comments) - 可选
```prisma
model Comment {
  id        String   @id @default(cuid())
  content   String   @db.Text
  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt

  postId    String
  authorId  String
  parentId  String?  // 回复评论
}
```

### 4.3 渲染策略规划

| 页面/功能 | 渲染策略 | 理由 |
|---------|---------|-----|
| 首页 | SSG | 内容相对固定,利于 SEO |
| 文章列表 | ISR (60s) | 需要展示最新内容,但不需要实时 |
| 文章详情 | SSG + ISR | SEO 友好,按需重新生成 |
| 分类/标签页 | SSG | 内容变化不频繁 |
| 搜索页面 | CSR | 需要用户交互,实时搜索 |
| 后台页面 | SSR + CSR | 需要权限验证,动态内容 |
| API Routes | Server-side | 后端逻辑 |

### 4.4 性能优化策略

1. **图片优化**: 使用 Next.js Image 组件,自动优化
2. **代码分割**: 动态导入,按需加载
3. **字体优化**: next/font 优化字体加载
4. **缓存策略**:
   - 静态资源: 长期缓存
   - API 响应: 根据业务设置缓存时间
   - ISR: 合理设置 revalidate 时间
5. **懒加载**: 图片、组件按需加载
6. **数据预取**: Link 组件预取功能

### 4.5 SEO 优化策略

1. **Metadata API**: 为每个页面设置合适的 meta 信息
2. **Sitemap**: 自动生成网站地图
3. **RSS Feed**: 生成 RSS 订阅源
4. **Robots.txt**: 配置搜索引擎爬虫规则
5. **结构化数据**: Schema.org 标记 (文章、面包屑等)
6. **语义化 HTML**: 正确使用 HTML5 标签
7. **Open Graph**: 社交媒体分享优化
